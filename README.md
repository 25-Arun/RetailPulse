# RetailPulse – AI Powered Retail Analytics

## Overview

RetailPulse is an end-to-end retail analytics project developed using the Online Retail II dataset.

## Features

- Data Cleaning
- Exploratory Data Analysis
- Customer Segmentation (RFM + KMeans)
- Demand Forecasting (Prophet)
- Inventory Risk Analysis
- Power BI Dashboard
- Streamlit Dashboard

## Technologies

- Python
- Pandas
- Scikit-learn
- Prophet
- Power BI
- Streamlit

## Dataset

Online Retail II – UCI Machine Learning Repository

## Results

- Revenue Analysis
- Customer Segmentation
- Demand Forecasting
- Inventory Recommendations
